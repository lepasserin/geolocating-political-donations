# The State of Out-of-district Donations in Canada

## Abstract

Political representation is fundamentally geographical, that is, in Canada Federal MPs represent geographical ridings. And yet, with various caveats, any Canadian living anywhere, can donate to any MP representing any riding. We examine the pattern of geographical political donations in Canada between 2013 and 2023. We document considerable out-of-riding donation patterns, especially differenced by an MPs race and gender. Our work has implications for thinking about the extent of political representation in Canada, and which parts of the population may be over- or under-represented.

## File Structure

The repository is structured as follows:

-   `data` contains the raw (i.e. source), cleaned, and processed data used to complete the paper.

-   `paper` contains the files used to generate the paper, including the Quarto document, the bibliography (.bib) file, and the renderted PDF of the paper.

-   `scripts` contains the R scripts used to process data (downloading, cleaning, subsetting, and testing), run analyses, as well as those used to create the polished visualizations present in the paper.

-   `other` contains the key resources consulted throughout development, as well as R objects for all the data visualizations (i.e. plots and tables) created in the visualziation scripts (saved as .rds files).
